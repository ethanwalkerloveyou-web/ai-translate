OpenAI 兼容配置

适用于任何兼容 /chat/completions 接口的服务

重要：Qwen3、GLM、豆包等模型在服务端默认开启思考，只是「不发送思考参数」并不会关掉它， 必须在这里显式发送关闭字段。OpenAI 官方接口留空即可。 DeepSeek 官方则是靠模型名区分：deepseek-reasoner 一定思考，deepseek-chat 不思考。

Anthropic 原生配置

直接对接 Claude 官方 Messages API

思考模式

语言

翻译 Prompt

导出配置

把全部模型配置和翻译设置存成一个 JSON 文件，换电脑或重装插件后直接导入，不用重新填一遍

注意：导出文件里的 API Key 是明文保存的，请妥善保管。 如果只是想把配置分享给别人，请取消勾选，导出的文件就不含 Key。

导入配置

选择之前导出的 JSON 文件恢复设置

导入会覆盖当前的全部设置，操作前会先弹窗让你确认。 兼容旧版本导出的文件，会自动升级成多配置结构。

关于 AI 划词翻译

一个轻量的浏览器划词翻译插件

  • 所有 API Key 与设置仅保存在浏览器本地 chrome.storage.sync 中，不经过任何第三方服务器中转。
  • 翻译请求由插件后台直接发送到你填写的 Base URL，请自行确认该地址可信。
  • 支持 OpenAI 兼容接口与 Anthropic 官方接口，可保存多套模型配置并随时切换。
  • 翻译弹窗可以按住标题栏拖动，滚动页面时不会消失。
  • 配置可在「导入导出」中备份成 JSON 文件，换设备时直接导入。
